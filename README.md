# 🎯 Number Guessing Game

A fun number guessing game built with Python!

## 🎮 Play the Game Online

👉 **[Click here to Play!](https://number-guessing-game--ommnayak010.replit.app)**

## 📖 How to Play

1. The computer picks a secret number between **1 and 100**
2. You try to guess the number
3. The game tells you if your guess is **too high** or **too low**
4. Keep guessing until you get it right!
5. Try to guess it in as few attempts as possible 🏆

## 🚀 Run Locally

If you want to run it on your own computer:

```bash
git clone https://github.com/ommnayak010/Number-Guessing-Game.git
cd Number-Guessing-Game/week1
python number_guessing_game.py
```
